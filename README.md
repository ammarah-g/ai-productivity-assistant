# AI Productivity Assistant

Build a modern, responsive SaaS web app called AI Workplace Productivity Assistant using React and Tailwind CSS.

Design: Create a clean, professional dashboard with a sidebar, top navigation, and three main tools. Use a dusty rose and sage green palette, warm cream backgrounds, rounded cards, subtle shadows, elegant typography, and minimalist icons. Ensure the layout works on desktop and mobile.

Features:

Smart Email Generator: Generate personalized professional emails from user input. Include Formal, Friendly, and Persuasive tone options.

AI Task Planner: Generate daily or weekly schedules from tasks, deadlines, and priorities. Organize tasks by urgency and importance.

AI Research Assistant: Summarize user-provided topics or articles and generate key insights and recommendations.

AI functionality: Use structured prompts and connect to Lovable's available AI integration so outputs are genuinely AI-generated, contextual, and not hardcoded or generic. Make all generated results editable, with copy and regenerate buttons.

Constraints: No backend, database, or authentication. Use client-side state and local storage where appropriate. Include a responsible AI disclaimer explaining that AI outputs may contain errors and should be reviewed.

Make the application feel like a polished, usable productivity tool, not a static landing page. Prioritize working AI features and a beautiful dashboard.
